# Divakar’s portfolio

Extract the entire ZIP. On Windows, double-click **Open Portfolio.cmd**. With Node.js installed it opens the complete portfolio on localhost without installing project dependencies. Keep the terminal window open while watching. **Portfolio.html** opens the full layout directly in a browser. Online video hosts may require an HTTP address and an internet connection.

The live YouTube and Vimeo players request muted autoplay when visible. Use the speaker control in the player to change sound. Instagram Reels use Instagram’s playback controls. Hover or focus a video to reach its original provider link.

To edit the source, install Node.js 22.12+ and run `npm install` followed by `npm run dev`. Run `npm run build` to regenerate Portfolio.html and the production site in dist. The page includes the portrait intro, showreel, all six scroll galleries and every portfolio section.
